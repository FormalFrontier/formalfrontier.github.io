• Nat.DivisionGrowth.affine_lower_bound: if 0 < s < n and ∀ m, n * (u m / s) ≤ u (m + 1), then for every m : ℕ, with λ = (n : ℚ) / s and C = (n : ℚ) * ((s - 1 : ℕ) : ℚ) / ((n : ℚ) - s), λ ^ m * ((u 0 : ℚ) - C) + C ≤ (u m : ℚ). There is no seed condition.
  • Nat.DivisionGrowth.eventually_dominates: under the same recurrence, 0 < s, 0 < b, s * b < n, and the sufficient natural seed n * (s - 1) < (n - s) * u 0, for each K : ℕ there is M : ℕ such that every m ≥ M satisfies K * b ^ m < u m.

The seed is sufficient, not necessary. See the mathematical guide for the precise Lean signatures, the rational shift, examples and boundary cases.
